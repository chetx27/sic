# Samsung Innovation Campus - AI & Machine Learning

This repository contains my learning, experiments, and practical work from the **Samsung Innovation Campus (SIC)** program.

The goal of this lab is to build a strong foundation in **Python, Data Science, Artificial Intelligence, and Machine Learning** through hands-on implementation and experimentation.

## What We Are Learning

The SIC journey will progress from programming and data handling fundamentals toward building and understanding AI/ML systems.

### 1. Python & Programming Foundations

* Python syntax and programming concepts
* Variables, data types, functions, loops, and conditional statements
* Lists, tuples, dictionaries, and sets
* Problem solving and basic programming logic

### 2. NumPy & Numerical Computing

We work with **NumPy** to understand how numerical data is represented and processed efficiently.

Current work includes:

* Creating and manipulating arrays
* 1D and multidimensional arrays
* Matrix operations
* Random number generation
* Zero-filled and constant-filled matrices
* Array copying and basic array properties
* Understanding array types and memory references

The current notebook in this repository documents these early experiments.

### 3. Data Handling & Analysis

Next, the focus moves toward working with real datasets:

* Data cleaning and preprocessing
* Missing-value handling
* Data transformation
* Exploratory Data Analysis (EDA)
* Statistical understanding of datasets
* Data visualization

Libraries such as **Pandas** and **Matplotlib/Seaborn** will be used for practical analysis.

### 4. Machine Learning

After developing the data-handling foundation, we move into Machine Learning concepts such as:

* Supervised and unsupervised learning
* Regression
* Classification
* Clustering
* Feature engineering
* Training and testing models
* Model evaluation
* Overfitting and underfitting
* Performance metrics

Python ML libraries such as **Scikit-learn** will be used to implement these concepts.

### 5. Artificial Intelligence

The later stages explore broader AI concepts and how intelligent systems learn from data.

This includes understanding:

* Artificial Neural Networks
* Deep Learning fundamentals
* Model architectures
* Training processes
* Optimization
* Prediction and inference
* Applications of AI to real-world problems

## Research & Project Direction

The knowledge gained through SIC will be applied toward a **research-oriented AI/ML project**.

The overall workflow will be:

**Data → Preprocessing → Analysis → Feature Engineering → Model Development → Evaluation → Results → Research Documentation**

The aim is not only to train models, but to understand **why a model works, how it can be evaluated, and how AI can be applied to meaningful real-world problems**.
